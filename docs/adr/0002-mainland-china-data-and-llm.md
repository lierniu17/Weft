# 面向中国大陆：数据存境内，使用国产大模型

Weft 第一版面向中国大陆用户。人际关系数据属于敏感个人信息，按《个人信息保护法》数据存放在境内云服务器；抽取与问答使用国产大模型，通过 OpenAI 兼容接口接入：对话与抽取以 DeepSeek 为主，向量模型用通义千问（`text-embedding-v4`）。不使用在大陆无法直接合规访问的 Claude / OpenAI。代码里保留一层大模型供应商抽象，以便切换。

## Consequences

- 第一版是邀请制内测，用邀请码加账号密码登录，暂不办理 ICP 备案和生成式 AI 算法备案。开放注册或对公众提供服务之前，必须先完成这两项备案，并接入手机号登录。
- DeepSeek 与千问是两家供应商，要分别配置密钥和限流，任何一家不可用都会影响录入或问答。
