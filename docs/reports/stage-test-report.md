1. **BOT-2 与“称谓人物”规则冲突**：BOT-2 的预期写在规则确定之前，已按规则修订 spec 与测试。

3. **“不喝酒”被归入相处之道**：已在抽取提示词中划清“喜好与厌恶（本人偏好与习惯）”与“相处之道（别人与他相处的注意事项）”。修复后留出集仍达标（人物 F1 0.983 / 关系类型 0.952 / 可信度 0.872），问答 43/43、编造率 0。
4. **BOT-13 过严**：真实模型会直接使用用户新增的自定义小类“球友”（这正是 AC-32 的要求），测试原先假设需要手动改。已放宽远程模式的这一步。

## 需要人工验收的重点

- 在手机宽度（375px）和桌面宽度（1440px）各走一遍：录入 → 草稿确认 → 人物页 → 关系页 → 问答。
- 抽取质量的真实体验：用你自己的写法记 5～10 条，看草稿里的人物对号、关系类型、可信度是否符合预期。
- 问答：问几个图谱里有和没有的问题，看回答和出处是否可信。
- 与高保真稿 `final.html` 并排的整体观感、动效、仅用键盘操作。
- 已知小问题：桌面端右栏打开时，在输入框按 Esc 也会关闭右栏；人物页、关系页、全景图页的侧栏仍是模态。
