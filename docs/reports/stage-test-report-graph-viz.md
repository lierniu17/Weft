## 过程中发现并修复

1. 内圈人名标签重叠、群体名压住环标签 → 新增确定性标签避让（纯函数 + 测试，375 / 1440、30 人与 200 人下无重叠）。
2. 问答卡片的相关人物里出现了本人 → 后端回答不再列出本人，前端也兜底过滤。
3. 端到端测试不清理 Neo4j，开发库累积 129 个租户 → e2e 前后自动清理（`pnpm e2e:clean`）。
4. 语义检索分数相同时取舍不确定，导致测试偶发失败 → 检索结果按分数、名称、id 稳定排序（仍只在本租户内检索）。
5. 图谱测试在构建版本上读不到图状态（图本身渲染正常）→ 测试在加载前开启测试钩子。

## 需要人工验收

- 打开 **全景图**：同心环、扇区、线型、光晕、图例是否好读；点一个人看聚焦与卡片；滚轮 / 双指缩放看人名出现。
- 拖动和播放 **时间轴**。
- 在对话里问“我是怎么认识 X 的？”，点 **“在图上查看”**（桌面在右栏打开）。
- 在“我的”里切换 **图谱外观：星空**，换浏览器重新登录看是否保持。
- 与原型并排的整体观感、动效手感（尤其手机真机）、只用键盘操作列表视图。
- 帧率是在本机 RTX 3060 Ti 上测的；没有独立显卡的设备可能更低。
