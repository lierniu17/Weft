## 样式改版做了什么

- 近黑主色 `#18181B` 只给主按钮、当前态、焦点；彩色只给状态；白底，内容直接铺开。
- 对话页：大圆角输入框为焦点，浅灰气泡，回答不套卡片，出处为小方块。
- 确认草稿：自然语句（“张伟喜欢钓鱼 · 本人说”），点一行改可信度；“老张 是 张伟”。
- 人物页：大头像 + 姓名 + 一句话关系 + 最多 2 个标签；空分区折叠成“还可以补充”；社会角色两行写法；手机上内容在前、关系图在后。
- 桌面内容限宽 720 居中，右栏 380，侧栏 232。
- 动效：页面切换、列表错开、抽屉滑入滑出、弹窗、按下反馈、数字滚动、骨架屏；**草稿入图谱**：抽屉退出 → 卡片收起 → 对勾画出 → 人物标签轻弹。减少动态效果时全部直接切换。
- 文案：内部字段名全部中文化（如“两人之间的事”）；图谱外观改名“浅色 / 星空”。
- 焦点环只在键盘操作时出现。
